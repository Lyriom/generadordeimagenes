# Segmentación SAM 2.1 (CPU). Se instala en la imagen (INSTALL_SAM=true).
#
# torch se instala APARTE y desde el índice de CPU, antes que este archivo:
#
#   pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
#   pip install --no-build-isolation -r requirements-sam.txt
#
# Los dos detalles importan:
#   - Sin el índice de CPU, pip trae la rueda con CUDA y las de nvidia-*: son
#     3 GB de más para un servidor que no tiene GPU.
#   - Sin --no-build-isolation, pip levanta un entorno aislado para compilar
#     sam2 y vuelve a descargar torch entero dentro.
#
# El commit va fijo a propósito: sam2 no publica en PyPI y se instala desde la
# rama principal, que puede cambiar cualquier día y romper una construcción que
# ayer funcionaba.
#
# La URL va suelta, sin el prefijo `sam2 @`: el paquete se declara a sí mismo
# como "SAM-2", y con el nombre puesto pip se va a buscar un "sam2" a PyPI —que
# existe y es otro proyecto distinto— y falla.
